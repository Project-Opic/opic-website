# 计量与运营方法论

**判据：「事实与原语在本域，方法与参数在外部」**——平台输出「多少钱、花在哪、谁承担、用得如何」四类事实；方法论在其上自由定义。

## 计量事实（平台承载）

成本记录按六维聚合维度记账；分摊规则原语（ratio 类型 + 比例归一强校验，未命中显式落 `unallocated` 黑洞不隐藏）；**账单可复现**（任一账单可从计量事实重放）；多轴计价：路径轴（online / batch / cached）× 承诺轴（standard / priority / reserved / spot），被抢占时段计价豁免；缓存 tokens 分列 + 让利显式；SLA 补偿凭证入账（与违约判定、SLO 定义三方闭环）。

## TCO 五要素归集（六维 → 五要素）

| TCO 要素 | 归集来源 | 口径 |
|---|---|---|
| ① 算力 | 计算资源维度 | 按分配台账占用事实折算 |
| ② 存储 | 存储维度 | 按存储实例利用率 |
| ③ 网络 | 网络维度 | 参数面 + 业务面流量 |
| ④ 运维 | 人力与工单维度 | 外部工单系统按中心归集 |
| ⑤ 电力与机房 | 能耗维度 | 机房计量事实 |

## 60:40 双权重分摊（配置法）

在分摊规则原语上配置两条 ratio 规则即可表达（如业务线 60% 按用量 / 部门 40% 按配额）；权重调整有审计、不追溯已封账账单。

## ROI 6:4 测算模板（外部计算）

```
ROI(周期) = (业务收益归集值 × 6) / (平台 TCO 归集值 × 4)
业务收益归集值 = Σ(挂靠应用调用量 × 单位收益系数)     ← 取数：成本账单（按应用维度）
平台 TCO 归集值  = 五要素合计                          ← 取数：成本账单 / 利用率报告
```

决策阈值建议：ROI ≥ 1.5 扩容线、1.0~1.5 维持线、< 1.0 专项复盘线。平台「建议零执行」——所有建议由人确认。
