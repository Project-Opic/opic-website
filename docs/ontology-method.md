# 本体论工程方法（核心差异化）

OPIC 与传统「需求文档 + 开发」的根本差异：**需求本身是一套可计算、可校验、可冻结的语义体系**。

## 九条横切判据

① 真相位置显式化 ② 写路径收敛（跨对象联动 = 0）③ 凭据谱系八位置 ④ 账本只增不改 ⑤ 审批判据家族（不可逆失效型 / 边界扩张型，无审批必有替代机制）⑥ 执行范式五语境 ⑦ 无副作用执行家族 ⑧ 重算代价判据 ⑨ 阻断在消费方。

## 四道机器闸门

| 闸门 | 校验 | 结果 |
|---|---|---|
| 独立审核（927 项） | 结构完整性、编号连续性、计数对账、审批口径 | FAIL 0 / WARN 0 |
| 一致性扫描 | 跨域引用、契约对称、时点残留、泄漏检查 | 断链 0 / 不对称 0 |
