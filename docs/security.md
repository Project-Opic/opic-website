# 安全与合规

## 凭据谱系八位置

平台内每一类凭据在谱系上有唯一位置与暴露上界：证书可导出（O-CRT）、集群 SSH 零持久化（O-CLC）、OS 使能零凭据借道（O-OSC）、镜像令牌只在内存流转、AI 令牌一次显示（O-APF）、共享库凭据（O-DBS）等。审计账本只增不改；安全事件与调用审计两流不合并（粒度、保留策略、消费者不同）。

## 内容合规（法定义务）

生成内容**标识三要素**（属性信息 / 提供者编码 / 内容编号）对标 GB 45438-2025（2025-09-01 施行）；备案状态机对接外部监管；**上线前置闸门**把合规从「事后审计」变成「发布阻断」；护栏档（GuardrailProfile）让同一策略按 ID 复用于任意接入点，未挂载接入点使用显式默认档。

## 零信任与机密计算

授权判定：Casbin RBAC 优先 → 拒绝则查 IdP → 任一通过即允许；判定与执行分离，阻断在消费方。机密计算部署档 + 节点 TEE 能力回源 + attestation 归第 3 层 + HYOK 密钥权威在租户侧。
