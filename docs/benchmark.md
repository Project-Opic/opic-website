# 业界对标（2026-09 刷新口径）

**20 条「缺则不合格」必备能力：达标 20/20。** 15 条经典必备（多租户与配额、Token 计量与缓存分列、流式与函数调用声明、gang 调度、算力切分语义、内容标识、模型退役承诺、SLA 治理、A/B 与数据飞轮、RAG 引用溯源等）+ 2025H2 新必备 5 项（Batch API、Prompt caching 计价、结构化输出/约束解码、护栏独立 API、模型退役公开承诺）。

## 已领先业界的点

- 判定/执行分离且阻断在消费方
- 账本只增不改 + 计价时点固化 + 缓存分列诚实口径
- MCP 安全边界（默认拒绝 + 审批前置——多数平台「只接不管」）
- 本体化需求工程（机器可校验的需求基线在业界罕见）
