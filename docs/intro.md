# OPIC 开放智能算力平台

OPIC 是一套**以本体论（Ontology）驱动**的智算 + MaaS 一体化平台：23 个能力域构成完整的语义层，覆盖从物理算力入网到 AI 应用消费的全链路。

## 三个差异化主张

1. **本体论驱动的需求工程**——需求是机器可校验的语义体系：每域一份《需求规格说明书》与《编制说明》，受 927 项自动审核、一致性扫描（130 条跨域引用零断链）、第九部分 13 项自检三道闸门约束，需求基线以 SHA-256 清单冻结。
2. **第 3 层可整体替换**——全部开源依赖被隔离在依赖层，替换引擎不触发需求变更；替换暴露语义缺口才走需求变更。
3. **业界对标 20 条必备全部达标**（2026-09 刷新口径，含 Batch 推理、结构化输出、护栏独立 API、缓存计价分列、模型退役承诺）。
