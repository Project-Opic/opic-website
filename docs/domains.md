# 23 个能力域

| 域码 | 域名 | 一句话定位 |
|---|---|---|
| O-SEC | 零信任安全中心 | 统一主体身份、会话、信任关系与授权决策 |
| O-ARC | 架构元数据域 | 错误码/元数据注册与 SDK 分发；全平台唯一真联动域 |
| O-SYS | 平台底座域 | 能力注册发现、RBAC、配置、审计、事件总线、网关 |
| O-DBS | 数据服务域 | 共享库实例供给、连接凭据、备份与高可用 |
| O-CRT | 证书信任域 | CA 树与证书全生命周期；凭据谱系第 1 位置 |
| O-VPN | 网络连通域 | 覆盖网络、节点入网、路由连通；双平面分离 |
| O-REG | 制品仓库域 | 制品/镜像仓库、凭据、缓存策略；托管 ≠ 编目 |
| O-AST | 资产域 | 节点资产台账、接入装配、巡检漂移；能力标签权威 |
| O-IGN | 交付执行域 | 蓝本版本目录、执行机调度、任务桥接 |
| O-CLC | 集群域 | K8s 集群与节点编排；唯一快照回滚 |
| O-OSC | 节点使能域 | OS 层算力使能包；借道式执行零凭据 |
| O-ADD | 集群扩展域 | 扩展组件目录、依赖解析、批量分发 |
| O-USR | 租户门户域 | 租户/成员/门户；镜子域零业务写入 |
| O-PIP | 流水线域 | 源码到制品；一次性 Job |
| O-APP | 应用域 | AI 应用生命周期（推理/智能体/训练/llm_app 四 kind） |
| O-CSC | 算力调度域 | 算力语义层；占用是台账事实不是对象状态 |
| O-APF | 接口与令牌域 | 路由、令牌、限流、计量；OpenAI 兼容契约 |
| O-MON | 可观测域 | 指标/日志/看板/通知；观测 ≠ 存储 |
| O-OPR | 运营成本域 | 成本采集、定价分摊、出账；账本只进不出 |
| O-DAT | 数据资产域 | 数据集版本、血缘、预处理标注；不经手字节 |
| O-MDL | 模型域 | 模型/评估账本/就绪判定/退役承诺 |
| O-KNB | 知识库域 | 知识库与检索治理；治理 ≠ 检索 |
| O-CMP | 内容合规域 | 审核判定链、生成内容标识、备案、前置闸门 |
